"# SnakeGame" 
🐍 Snake Game
A classic, browser-based Snake Game built with a modern dark-mode aesthetic. This project features arcade-style sound effects, customizable difficulty settings, and a dual-control system designed for both desktop and mobile play.

🎮 How to Play
Start the Game: Select your preferred speed and click the START GAME button or press Spacebar.

Control the Snake: Use the Arrow Keys on your keyboard or tap the On-Screen Directional Pad.

Objective: Eat the red food squares to grow your snake and increase your score.

Avoid Collisions: The game ends if the snake hits the walls or its own body.

🚀 Key Features
Persistent Speed Settings: Choose from Slow, Normal, Fast, or Insane modes. The game remembers your choice even after a restart.

Dual Controls: Seamlessly switch between keyboard inputs and touch-friendly on-screen buttons.

Procedural Audio: Built-in arcade sound effects (Start, Eat, and Game Over) generated via the Web Audio API—no external MP3 files required.

Start/Restart Overlay: A clean menu system that pauses the game until you're ready to play.

Responsive Design: Optimized for both mobile browsers and desktop screens.

🛠️ Built With
HTML5 Canvas: For high-performance 2D rendering.

CSS3: Featuring a custom Grid-based D-Pad and a dark-themed UI.

Vanilla JavaScript: Clean, modern JS logic without the need for external libraries or frameworks.

📂 Installation
No installation is required. Simply download the snake.html file and open it in any modern web browser.
